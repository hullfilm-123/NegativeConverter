# NegativeConverter
네거티브 → 포지티브 변환  (라이트룸 클래식 플러그인)
=====================================================
버전  : v0.9.0-beta.1  (2026-11-26)  베타 테스트용

디지털 카메라로 찍은 컬러 네거티브 필름 사진(RAW)을 라이트룸 클래식 안에서 정상 색(포지티브)으로 바꿔 줍니다.
RAW 파일은 건드리지 않고, 변환 결과를 라이트룸의 "현상 설정"(채널별 톤 커브 + 자르기)으로 사진에 적용합니다.
언제든 [선택한 사진 원래대로] 로 변환 전 상태로 되돌릴 수 있습니다.

  A. 변환 패널   미리보기를 보면서 조정하고, 사진마다 확인한 뒤 적용합니다. (주로 쓰는 방식)
  B. 내보내기    파일 > 내보내기 에서 고화질 JPG · 16비트 TIFF 파일로 저장합니다. (파란 채널 복원이 들어 있어 최종 결과물용으로 권장)

목차
  1. 베타 테스트 안내
  2. 사전 준비 (라이트룸 클래식만 있는 분은 여기부터)
  3. 플러그인 설치
  4. 사진 촬영(스캔) 조건
  5. 변환 패널 사용법
  6. 화면 설명 (Convert · Edit · 세부 설정)
  7. 내보내기(파일 저장) 사용법
  8. 문제 해결
  9. 알아 둘 점
  10. 문제를 알려 주실 때


1. 베타 테스트 안내
-------------------------------------------------------------
  - 베타 버전입니다. 개발자의 PC(Windows 11 + Lightroom Classic)에서 실제로 쓰며 다듬었고, 다른 환경에서는 이제 확인하는 단계입니다.
    macOS 는 시험하지 못했습니다.
  - 변환 결과는 사진의 "현상 설정"에만 기록되고 원본 RAW 는 바뀌지 않습니다. 그래도 처음 쓰기 전에 카탈로그를 백업해 두세요
    (라이트룸: 편집 > 카탈로그 설정 > 일반 > 백업 — macOS 는 Lightroom Classic > 카탈로그 설정 — 에서 "라이트룸을 끌 때 백업" 을 고르면 됩니다).
  - 처음에는 사진 한 장으로 해 보세요. 문제가 있으면 [선택한 사진 원래대로] 로 되돌릴 수 있습니다.
  - 버전은 패널 제목, 플러그인 관리자, 로그에 표시됩니다. 패치가 나올 때마다 버전이 올라가고 CHANGELOG_ko.txt 에 기록됩니다.


2. 사전 준비 (한 번만)
-------------------------------------------------------------
  이 플러그인은 색 계산을 파이썬(Python)으로 합니다. 라이트룸만으로는 동작하지 않고, 아래 세 가지가 필요합니다.

    ① Lightroom Classic
    ② Python 3  (64비트)
    ③ 파이썬 패키지 numpy, opencv-python

  필요한 디스크 공간은 합쳐서 수십~100MB 정도이고, 설치할 때만 인터넷이 필요합니다. 플러그인을 쓸 때는 인터넷이 필요 없습니다.

  2-1. Lightroom Classic
       - 이름이 "Lightroom Classic" 인 프로그램이어야 합니다. 클라우드형 "Lightroom" (Classic 이 붙지 않은 것)은 플러그인을 지원하지 않습니다.
       - 최신 버전을 권장합니다. 새 카메라의 RAW 는 최신 버전에서만 열리고, 오래된 버전은 시험하지 못했습니다.

  2-2. Python 설치  (Windows)
       1) 웹 브라우저에서  https://www.python.org/downloads/  로 가서 Windows 용 설치 프로그램(Python 3, 64비트)을 받습니다.
       2) 설치 프로그램 첫 화면에서 맨 아래 "Add python.exe to PATH" 를 체크하고 [Install Now] 를 누릅니다.
          (플러그인은 설치 때 함께 들어가는 "py" 라는 실행기로도 파이썬을 찾으므로 이 체크가 꼭 필수는 아니지만, 켜 두면 편합니다.)
       3) 설치가 끝나면 닫습니다.
       ※ 파이썬이 이미 설치돼 있다면 2) 는 건너뛰고 2-3 으로 가세요.

  2-3. 패키지 설치 (numpy, opencv-python)
       1) 윈도 시작 메뉴에서 "cmd" 를 입력해 "명령 프롬프트" 를 엽니다.
       2) 아래 한 줄을 붙여 넣고 Enter 를 누릅니다. (끝날 때까지 잠깐 걸립니다)

            py -m pip install numpy opencv-python

          "py 는 내부 또는 외부 명령이 아닙니다" 라고 나오면 파이썬이 설치되지 않았거나 설치 때 "py launcher" 를 뺀 것입니다.
          이때는 대신  python -m pip install numpy opencv-python  을 입력해 보세요.
       3) 설치 후 확인: 아래를 입력해서 OK 가 나오면 준비가 끝난 것입니다.

            py -3 -c "import numpy, cv2; print('OK')"

          (플러그인도 같은 방법으로 "py -3", "python", "python3" 순서로 시험해서 numpy 와 OpenCV 가 되는 파이썬을 찾습니다.)

  2-4. macOS 에서
       터미널에서  python3 --version  으로 파이썬을 확인하고 (없으면 python.org 에서 설치),
       python3 -m pip install numpy opencv-python  을 실행한 뒤  python3 -c "import numpy, cv2; print('OK')"  로 확인합니다.
       (macOS 는 시험하지 못해서 이 방법이 그대로 안 될 수 있습니다.)

  2-5. 잘 안 될 때
       - pip 설치가 "빌드 실패 / No matching distribution" 같은 오류로 끝나면, 너무 새 파이썬이라 패키지가 아직 없는 경우가 많습니다.
         python.org 에서 한 단계 이전의 안정 버전을 설치해서 2-3 을 다시 해 보세요.
       - 파이썬이 여러 개 설치돼 있어 엉뚱한 것이 잡히면, 플러그인 패널 Convert 탭 아래의 "Python 명령" 칸에 numpy 와 OpenCV 를 설치한
         python.exe 의 전체 경로를 적으세요 (명령 프롬프트에서  py -0p  또는  where python  으로 경로를 볼 수 있습니다).
       - "Windows 스마트 앱 컨트롤" 이나 보안 프로그램이 파이썬 패키지의 파일을 막으면 "DLL load failed ... 애플리케이션 제어 정책에서
         이 파일을 차단했습니다" 같은 메시지가 납니다. 이 플러그인은 막히기 쉬운 부분을 쓰지 않게 만들었지만 PC 마다 다를 수 있으니,
         메시지에 나온 파일 이름을 알려 주세요 (8번 참고).


3. 플러그인 설치
-------------------------------------------------------------
  1) 받은 zip 파일을 "압축 풀기" 합니다. (zip 안에서 바로 실행하지 마세요. 폴더가 통째로 풀려야 합니다.)
  2) 풀린  NegativeConverter.lrplugin  폴더를 계속 둘 자리(예: 문서 폴더 안)에 옮깁니다. 나중에 옮기거나 지우면 플러그인이 사라집니다.
     한글 경로여도 됩니다.
  3) 라이트룸 클래식: 파일 > 플러그인 관리자 > [추가…] > NegativeConverter.lrplugin 폴더를 선택 > [완료]
  4) 플러그인 목록에 "네거티브 → 포지티브 변환 (베타)" 가 보이고, 설치되어 실행 중이라고 표시되면 끝입니다. (오류 문구가 보이면 그 내용을 알려 주세요.)
  - 새 버전으로 바꿀 때: 라이트룸을 끄고 기존 NegativeConverter.lrplugin 폴더의 내용을 새 폴더로 덮어쓴 뒤 라이트룸을 켭니다
    (라이트룸을 켜 둔 채라면 플러그인 관리자에서 [다시 로드]).


4. 사진 촬영(스캔) 조건
-------------------------------------------------------------
  디지털 카메라로 필름을 찍은 RAW 사진이 대상입니다. 이 조건이 맞아야 자동 분석이 됩니다.
  - 필름의 구멍(퍼포레이션, 스프로킷 구멍)이 사진의 위쪽과 아래쪽 가장자리에 6개 이상, 잘리지 않고 온전히 보여야 합니다.
    구멍으로 새어 나온 광원의 빛으로 화이트밸런스를, 구멍 사이 필름 여백으로 필름 베이스(주황색 마스크) 색을 잡습니다.
    구멍을 못 찾으면 변환이 되지 않고 "no perforations found" 같은 메시지가 나옵니다.
  - 필름이 가로로 놓여 구멍이 위 · 아래로 보여야 합니다. 라이트룸에서 사진이 세로로 보여 구멍이 좌우에 있다면 라이트룸에서
    가로로 보이게 회전해 두세요 (이 경우는 시험해 보지 못했습니다).
  - 그림 부분(프레임)은 자동으로 찾아 자릅니다.
  - 파란색이 날아가지 않게 조금 밝게 찍는 쪽이 좋습니다. 어두운 네거티브는 파란 빛이 거의 통과하지 못해 값이 0 으로 잘리기 쉽고,
    그러면 파란 기가 남습니다 (파란 채널은 필름 여백 기준보다 2~3 스톱 더 밝게 노출해야 남는 경우가 많습니다. 빨강 · 초록이 날아가면 브라케팅하세요).
  - 라이트룸 현상 모듈의 프로필은 가장 평평한 것(Adobe Raw / 카메라 중립 / Flat 계열)을 권장합니다. 화이트밸런스는 신경 쓰지 않아도 됩니다.


5. 변환 패널 사용법
-------------------------------------------------------------
  1) 변환할 RAW 사진을 선택합니다 (여러 장 가능).
  2) 파일 > 플러그인 추가 기능 > "네거티브 변환 패널 열기…"  (라이브러리 모듈에서는 라이브러리 > 플러그인 추가 기능 에도 있습니다.)
  3) Convert 탭에서 컬러 모델 등을 고르고 [변환 시작 (선택한 사진)] 을 누릅니다.
     첫 사진부터 분석합니다 (사진당 몇 초). 분석하는 동안 라이트룸이 잠깐 평평한 네거티브 상태로 보이는 것은 정상입니다.
  4) 분석이 끝나면 Edit 탭으로 넘어가고 미리보기에 결과가 나옵니다. 슬라이더를 움직이면 잠시 뒤 미리보기가 바뀝니다.
       - ↶ ↷ : 미리보기를 90도씩 돌려서 봅니다 (세로 사진 확인용. 사진 자체는 바뀌지 않습니다).
       - [크게 보기] : 미리보기를 큰 창에 더 자세히 보여 줍니다. 열려 있는 동안에는 패널을 조작할 수 없으니 [닫기] 를 누른 뒤 조정하세요.
       - A/B (처음 값과 비교) : 켜면 처음 변환했을 때의 값으로, 끄면 지금 값으로 미리보기가 바뀝니다.
  5) 마음에 들면 [확인 · 적용하고 다음으로] 를 누릅니다. 이때 비로소 사진에 결과가 적용됩니다.
       (적용하지 않고 넘어가려면 [이 사진 건너뛰기], 멈추려면 [중단] — 둘 다 이번 변환을 시작하기 직전 상태로 되돌립니다.)
  6) 적용한 뒤 라이트룸이 실제로 그린 결과가 미리보기 칸에 한 번 더 나옵니다 (세부 설정 포함). 여기서 고릅니다.
       [결과 좋음 · 다음으로]  그대로 두고 다음 사진으로
       [다시 조정]           슬라이더가 다시 열립니다. 고친 뒤 [확인] 을 누르면 새 값으로 다시 적용합니다.
       [이 사진 변환 취소]    이번 변환을 시작하기 직전 상태로 되돌리고 다음 사진으로
     (Convert 탭의 "[확인] 뒤 라이트룸 실제 결과를 다시 보여주기" 를 끄면 이 단계 없이 바로 다음 사진으로 넘어갑니다.)
  - 여러 장을 한꺼번에 선택해도 사진마다 따로 보정하고 따로 확인합니다.
  - 나중에 다시 고치기: 사진을 선택하고 Convert 탭의 [선택한 사진 다시 조정].
    변환했을 때의 값에서 다시 시작합니다. (도중에 건너뛰거나 중단하면 다시 조정하기 직전의 결과로 돌아갑니다.)
  - 변환 전으로 되돌리기: 사진을 선택하고 Convert 탭의 [선택한 사진 원래대로].
    처음 변환하기 직전의 현상 설정 전체를 복원합니다. 변환 뒤에 현상 모듈에서 손댄 것도 바뀐 항목은 모두 되돌립니다.
    기록은 라이트룸을 껐다 켜도 남습니다 (같은 카탈로그에서). 라이트룸의 현상 히스토리에도 "네거티브 변환: …" 단계가 남습니다.


6. 화면 설명
-------------------------------------------------------------
  [Convert 탭]
    - 종류 / 소스 : 컬러 네거티브 / 디지털 카메라 (이 두 가지만 지원합니다).
    - 컬러 모델 : 스캐너 색감입니다.
        기본  스캐너 룩 없음. 디지털 카메라의 RAW 처럼 가장 기본적인 변환입니다. 대비를 더하지 않아 노리츠보다 밋밋하게 나옵니다.
        노리츠 (HS-1800)  기준이 되는 일반적인 결과입니다. (처음 켰을 때의 선택)
        프론티어 (후지 SP-3000)  밝은 부분을 살짝 누르고 채도를 조금 낮춥니다.
      고른 모델은 다음에도 기억합니다. 미리보기를 보는 중에 바꿔도 바로 반영됩니다. 세 모델 모두 Edit 탭 슬라이더는 그대로 두면 됩니다.
      (프론티어 · 노리츠 모델은 소수의 비교 사진에서 본 경향이라 스캐너를 그대로 재현한 것은 아닙니다. 기술메모_ko.txt 참고)
    - 기본 채도 (Pre-Saturation) : 1~5, 3 이 보통입니다.
    - 여백 (경계 버퍼) % : 자르기 경계를 안쪽으로 더 줄입니다 (필름 가장자리 흔적이 보일 때).
    - 프레임에 맞춰 자르기 / 자동 노출.  자동 자르기가 어긋나면 "프레임에 맞춰 자르기" 를 끄고 라이트룸 자르기 도구로 직접 자르세요.
    - 채도를 라이트룸에 적용하지 않기 : 결과 화면의 색이 미리보기와 다르게 어긋날 때 켭니다 (채도는 라이트룸에서 직접 조절).
    - Python 명령 : 비우면 자동으로 찾습니다 (2-5 참고).
  [Edit 탭]
    - 프리셋 : 표준, 따뜻하게, 차갑게, 선명하게, 부드럽게, 빛바랜 필름 + 내가 저장한 것(★). 고른 프리셋은 기억해 다음 사진의 시작 값으로 씁니다.
    - 내 프리셋 : 이름을 적고 [저장] 하면 지금 값이 목록에 ★ 로 저장됩니다. 목록에서 고르고 [삭제] 로 지웁니다.
    - 복사 / 붙여넣기 : 한 사진의 보정 값을 다른 사진에 붙여넣습니다. 되돌리기 : 직전의 프리셋 · 톤 프로필 · 붙여넣기 · 전체 초기화를 한 단계 되돌립니다.
      [모든 슬라이더를 처음 값으로] : 이 사진을 처음 변환했을 때의 값으로.
    - 톤 프로필 : 소프트 / 하드 / 밝은(어두운) 부분 하드 · 소프트 / 플랫 / 리니어. 대비 · S자 · 밝기 계열 슬라이더만 바뀝니다.
    - 슬라이더 : 노출, 대비(감마, 낮을수록 강함), S자 커브, 밝기, 라이트, 다크, 화이트, 블랙, 페이드(검정 띄우기), 채도, 밝은 부분.
      Soft Highs / Soft Lows 는 밝은 곳 · 어두운 곳이 딱 잘리지 않고 부드럽게 눌리게 합니다.
      화이트 / 블랙 클립 % : 기본 분석보다 더 많이(+) 또는 덜(−) 잘라내는 비율입니다. 슬라이더 옆 < > 로 한 칸씩, ↺ 로 그 슬라이더만 처음 값으로.
    - 색 균형 (WB / 중간톤 / 밝은 곳 / 어두운 곳) : WB 는 노랑 ↔ 파랑 · 마젠타 ↔ 초록. 나머지는 해당 톤 영역에 색을 더합니다.
    - "다음 사진에도 현재 값 유지" 를 켜면 다음 사진을 이 사진에서 조정한 값(회전 각도 포함)으로 시작합니다.
  [세부 설정 탭]  선명도 · 선명도 반경 · 노이즈 감소 · 색 노이즈 감소 · 입자 · 명료도 · 질감
    라이트룸 자신의 현상 설정으로 들어가므로 [확인] 을 누를 때 사진에 적용되고, 패널 미리보기에는 보이지 않습니다
    (확인 뒤 나오는 라이트룸 결과 화면이나 라이트룸 화면에서 보세요). 변환 전에 이 값들을 손봐 둔 사진은 [확인] 때 패널의 값으로 바뀝니다.


7. 내보내기(파일 저장) 사용법
-------------------------------------------------------------
  변환 패널과 별개로, 변환된 파일을 바로 저장하는 방식입니다. 파란 채널 복원이 들어 있어 파란 기가 가장 잘 잡힙니다.
  (컬러 모델 · 프리셋 · 톤 조절 · 세부 설정은 이 방식에는 들어 있지 않고, 감마 · 노출 · 색 슬라이더만 있습니다.)
  (권장) 같은 필름 사진을 모두 선택 > 라이브러리 > 플러그인 추가 기능 > "네거티브 스캔용 중립 현상 적용"
  1) 변환할 사진을 선택합니다.
  2) 파일 > 내보내기… > 맨 위 "내보내기 대상" 에서 "네거티브 → 포지티브 변환" 을 고릅니다.
  3) "파일 설정" 이 TIFF / 색 공간 ProPhoto RGB / 16비트 인지 확인합니다 (창을 열 때 그렇게 맞춰 둡니다).
  4) 감마 · 노출 · 색 슬라이더와 결과 저장 위치를 정하고 [내보내기].
  결과 : 프레임만 잘라낸 JPG(_positive_crop.jpg), 전체(_positive_full.jpg), 16비트 TIFF(_positive_crop_16bit.tif). 사진당 10~30초 걸립니다.


8. 문제 해결
-------------------------------------------------------------
  변환이 실패하면 패널 상태 칸(또는 안내 창)에 오류 문구와 로그 파일 위치가 나옵니다.
    변환 로그 : %TEMP%\NegConvert\log.txt, lrlog.txt  (임시 폴더 경로에 한글이 있으면 C:\Users\Public\NegConvert\)
    라이트룸 쪽 로그 : 문서\LrClassicLogs\NegConvert.log
  - "Python 을 찾지 못했습니다" : 2번의 준비가 안 된 것입니다. 2-3 의 확인 명령이 OK 를 내는지 보세요. 되는데도 안 되면 "Python 명령" 칸에
    python.exe 전체 경로를 적습니다 (2-5).
  - "no perforations found" / "only N perforations found" : 필름 구멍을 못 찾았거나 6개 미만입니다. 4번의 촬영 조건
    (위 · 아래 가장자리에 구멍이 온전히 보이게, 가로 방향)을 확인하세요.
  - "DLL load failed … 애플리케이션 제어 정책에서 이 파일을 차단했습니다" : Windows 보안 기능(스마트 앱 컨트롤 등)이 파이썬 패키지의 파일 하나를
    막은 것입니다. 메시지에 나온 파일 이름(예: _bounded_integers)을 알려 주세요.
  - "write access call 에 막혔습니다" 류의 메시지 : 다른 플러그인이나 라이트룸 자신이 카탈로그에 쓰고 있을 때 나옵니다. 플러그인이 알아서
    기다렸다가 다시 시도합니다. 그래도 안 되면 가져오기 · 동기화 등이 끝난 뒤 다시 누르거나 라이트룸을 다시 시작하세요.
  - 미리보기가 안 바뀜 : 패널 상태 칸의 문구("미리보기를 만들지 못했습니다 …")와 로그(%TEMP%\NegConvert\lrlog_*.txt)를 알려 주세요.
  - 패널이 메뉴에 안 보임 : 플러그인 관리자에서 이 플러그인이 설치되어 실행 중인지 보고, 파일 > 플러그인 추가 기능 을 확인하세요.
  - 변환 후 색이 이상하게 어긋남 : 상태 칸의 "커브 적용 확인 … 오차" 숫자를 알려 주세요 (1.5 를 넘으면 라이트룸의 커브 처리가 예상과 다르다는 뜻입니다).
    파랗게 나오면 Convert 탭의 "채도를 라이트룸에 적용하지 않기" 를 켜 보세요.
  - 변환한 뒤 사진이 이상한 채로 남았을 때 : [선택한 사진 원래대로] 를 한 번 누르면 정리됩니다.


9. 알아 둘 점
-------------------------------------------------------------
  - [확인] 을 누르기 전에는 사진의 현상 설정에 변환 결과가 들어가지 않습니다. 분석하는 동안 라이트룸에는 평평한 네거티브로 보이고,
    결과는 패널 미리보기로 확인합니다.
  - 미리보기는 라이트룸이 실제로 적용할 커브를 계산해 그린 화면입니다 (채도는 근사). 100% 확대 수준의 확인은 [확인] 뒤 라이트룸 화면에서 하세요.
  - 변환 후에는 라이트룸 기본 패널의 노출 · 대비 · 하이라이트 · 섀도 · 화이트 · 블랙 슬라이더가 반대로 움직입니다 (톤 커브로 반전했기 때문).
    톤 조절은 변환 패널의 슬라이더로 하세요.
  - 톤 커브 방식(패널)은 파일 저장 방식(7번)보다 거칠 수 있고, 라이트룸이 이미 잘라낸 파란 채널은 복원하지 못합니다.
    파란 기가 남으면 7번의 내보내기를 쓰세요.
  - 패널 창은 가로로 넓습니다 (약 1000px).
  - 아직 없는 것 : 롤 전체 동기화, 고급(Advanced) 탭, 포지티브 복사본 만들기, 스포이트로 회색 찍기, 흑백 네거티브 · 슬라이드 필름.
  - 개발 · 시험 내용은 기술메모_ko.txt 에 있습니다. 읽지 않아도 쓰는 데 지장 없습니다.
